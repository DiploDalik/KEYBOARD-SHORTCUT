KEYBOARD SHORTCUTS

BY DIPLODALIK

Copy

Copies the selected content.

ctl + C

Paste

Pastes the copied content.

ctrl + V

Cut

Cuts the selected content.

ctrl + X

Undo

Reverses the last action.

ctrl + Z

Select all

Selects all content.

ctrl + A

Save

Saves the current file.

ctrl + S

Find

Searches for text in the current document or page.

ctrl + F

Print

Opens the print dialog.

ctrl + P

Switch window

Switches between the open applications.

Alt + Tab

Show desktop

Shows or hides the desktop.

Win + D

File explorer

Opens windows file explorer.

Win + E

Lock screen

Locks your computer.

Win + L
